# تطبيق طباعة الصور — كولاج

تطبيق ويب يعمل على **الآيفون والأندرويد (جالكسي)** بدون متاجر تطبيقات.
الزبون يفتح الرابط، يركّب صوره في تصميم كولاج، ويرسل لك الصورة النهائية عبر واتساب بعد الدفع.

## الخصوصية 🔒

- **صور الزبون لا تغادر جهازه أبداً** — كل المعالجة (التركيب، القص، التصدير) تتم داخل متصفحه.
- لا يوجد خادم ولا قاعدة بيانات ولا رفع ملفات.
- الشيء الوحيد الذي يصلك هو **الصورة النهائية** التي يرسلها الزبون بنفسه عبر واتساب.

## ما يقدر يسويه الزبون

1. يختار **المقاس** (10×15، 13×18، مربع، A5، A4) ويشوف **السعر**.
2. يختار تصميم الكولاج: **بدون إطار** أو **بإطار** (29 تصميماً من صورة واحدة حتى 16 صورة)، عمودي أو أفقي.
3. يضيف صوره: سحب لتحريك الصورة داخل الخانة، قرص إصبعين للتكبير، تدوير، استبدال، حذف.
4. يصدّر التطبيق ملفاً **بجودة الطباعة (300dpi)** ويرسله لك واتساب مع تفاصيل الطلب والسعر.

## إعداداتك — ملف واحد فقط

افتح `config.js` وعدّل:

- `businessName` — اسم محلّك.
- `whatsapp` — **رقمك** بصيغة دولية بدون + (مثال: `9665XXXXXXXX`). ⚠️ لازم تعدّله قبل الاستخدام.
- `currency` — العملة.
- `paymentNote` — تعليمات الدفع التي تظهر للزبون.
- `sizes` — المقاسات والأسعار (تقدر تحذف أو تضيف).

## كيف يثبّته الزبون على جواله؟

- **آيفون:** افتح الرابط في Safari ← زر المشاركة ← **"إضافة إلى الصفحة الرئيسية"**.
- **جالكسي/أندرويد:** افتح الرابط في Chrome ← القائمة ⋮ ← **"إضافة إلى الشاشة الرئيسية"**.

بعد التثبيت يشتغل مثل أي تطبيق، حتى **بدون إنترنت**.

## النشر

المجلد ثابت بالكامل (HTML/CSS/JS) — ينشر على أي استضافة ثابتة:
GitHub Pages أو Netlify أو Cloudflare Pages. المطلوب فقط أن يكون الرابط `https` (شرط لعمل التثبيت ومشاركة الملفات).

> ⚠️ **مهم:** هذا المستودع يحتوي مشروعاً آخر خاصاً (سجل الزيارات). الأفضل نشر هذا التطبيق
> في مستودع مستقل حتى لا يختلط تطبيق الزبائن بالملفات الخاصة.

## الملفات

```
index.html            الواجهة (٤ شاشات: المقاس ← التصميم ← المحرر ← الطلب)
config.js             ← إعداداتك (الاسم، الواتساب، الأسعار)
css/app.css           التصميم — عربي RTL، جوال أولاً
js/layouts.js         قوالب الكولاج (29 قالباً)
js/app.js             المنطق: اللمس، الرسم، التصدير 300dpi، الإرسال
manifest.webmanifest  تعريف التطبيق للتثبيت على الجوال
sw.js                 العمل بدون إنترنت
icons/                أيقونات التطبيق
```
